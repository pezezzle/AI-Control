# Build and test status

Version 0.4.9 was built and tested on Windows with an RTX 4090 on October 7, 2026. The interface, documentation, host dialogs and launcher messages are in English.

## Automated checks

`Build.ps1 -Verify` builds without warnings or errors and runs 187 C# checks, six process identity checks, one lifecycle check with a real short-lived test process, and 45 browser tests: **239 checks in total**.

Version 0.4.9 removes the independent 2,048-token summary output cap. Summary requests use measured remaining model context, request concise memory and retry a smaller source segment after actual output exhaustion. Only complete summaries advance the source position; truncated text cannot enter working memory. Regression checks cover a complete summary beyond 2,048 tokens, measured capacity, shrinking retries without skipped/duplicated source data, exact checkpoints, sending a fitting new prompt after proactive summary failure, blocking actual overflow and blocking checkpoint-storage failure.
