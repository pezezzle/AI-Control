    Getting started
    1. Start the coding server with your chosen model.
    2. Open Assistant and choose a working folder using File → Choose workspace or the chat gear.
    3. Select the same model in the composer, then enter your request.
    File access
    Read only reads files. Review writes asks before saving. Workspace write creates and changes files in the selected folder without asking, and backs up previous versions before overwriting.
    Scripts need their own enabled setting and approval; they run with your Windows account and can act outside the folder. Workspace write grants file access within the selected folder.
    Task progress shows completed actions and saved files. /context toggles context status. Closing cancels active assistant tasks and stop schedules; servers keep running.
